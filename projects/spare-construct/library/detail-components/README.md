# Detail components

Our own 2D designs for detail views: a timber section, a blocking cross and an insulation batt. A
detail component has lines and fills in its own frame and no 3D, no parameters and no host, so it
shows only in the view it is placed in. The format is in
`projects/spare-construct/crates/construct-detailing/FORMAT.md` and its schema in
`projects/spare-construct/crates/construct-detailing/schema/detail-component-1.schema.json`.
