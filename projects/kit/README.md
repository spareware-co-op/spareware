# Shared kit

What every Spareware program is built on.

- `crates/`: libraries compiled into every app (core types, operations, storage, sync, plugins, AI access, the marketplace engine).
- `services/`: services that run once and every app connects to (accounts, payments, matching, maps, messaging, trust, voting, ledger).
