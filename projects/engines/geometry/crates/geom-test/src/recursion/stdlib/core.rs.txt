// The recursion check's model of the standard library (`core`, `alloc` and `std`), read by
// `geom-test`'s recursion check in place of their source (src/recursion/stdlib.rs). It is never
// compiled: it is Rust the check's type checker reads, written from the standard library's
// documented signatures (https://doc.rust-lang.org/std/), with a body for every function that
// calls back into what it is handed (a closure, or a trait method of a type parameter), calling
// exactly that. A function that calls nothing back has the body `loop {}`, whose type `!` fits
// any result. Iterator adapters keep their closures in their structs and call them in `next`,
// as the library does; adapters whose item type a closure gives carry it as a type parameter of
// their own (`Map<I, F, B>`). Where the library takes `&dyn Debug` and calls it at once
// (`DebugStruct::field`), the model takes `&V` with `V: Debug`, which runs the same method of the
// same value.

pub fn any<T>() -> T {
    loop {}
}
